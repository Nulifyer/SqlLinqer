Measurement scope

Database setup occurs outside measurement processes. Each worker warms both paths with 128 rows and runs in isolation. Managed memory is sampled every 5 ms. Allocations span all managed threads. Timing includes loading, processing, and disposal. Collect-all intentionally retains every object. DuckDB uses two query threads and a 1 GiB engine memory limit. Linux x64, .NET 10.0.13. No remote server performance was measured.
