# SqlLinqer.Diagnostics

Optional ILogger and ActivitySource instrumentation for SqlLinqer. Attach `SqlLinqerDiagnostics` through `ConnectorOptions.Observer`. SQL, values, and exception details are disabled by default. Subscribe to the `SqlLinqer` ActivitySource for tracing.

This optional package is under development. See the [repository documentation](https://github.com/Nulifyer/SqlLinqer/tree/master/docs) and runnable `samples/SqlLinqer.MinimalApi` example for usage and lifetime details.
